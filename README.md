# wasla_app
وصلة WASLA هو مشروع رقمي متكامل يهدف إلى تسهيل طلب الطعام من المطاعم المحلية في القاهرة الجديدة، من خلال منصة تجمع العملاء والمطاعم في مكان واحد، وتوفر تجربة استخدام بسيطة وسريعة عبر تطبيق الهاتف والموقع الإلكتروني.  تتيح المنصة للمستخدمين اكتشاف المطاعم القريبة، واستعراض قوائم الطعام والصور والأسعار والتفاصيل،
